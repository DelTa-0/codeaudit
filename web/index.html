CodeAudit — AI Technical Debt Intelligence

CodeAudit audits GitHub repositories for the technical debt AI coding assistants leave behind. It verifies every declared and imported dependency against the live npm and PyPI registries, so packages that do not exist — the ones language models invent and attackers then register — are caught before they reach your main branch.

It also reports:

  • Known vulnerabilities in declared and transitive dependencies
  • Hardcoded secrets, in git history as well as the working tree
  • Unreferenced code that no longer has a caller
  • Prompt injection and unsafe configuration in the instruction files an AI agent trusts — CLAUDE.md, AGENTS.md, MCP server configs and skill files

It runs as a hosted dashboard with a GitHub App, and as a command-line tool that needs no account. Sign in with a link sent to your email address, or with GitHub.
